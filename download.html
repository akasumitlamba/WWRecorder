Having trouble?
If Edge blocks the file, or Windows shows SmartScreen or Smart App Control, keep this page open and use the steps below. Do not bypass a warning for a file from an unexpected address.

Prefer the simplest route? Install from Microsoft Store.

If the installer is blocked

Match the message you see.

01Edge blocks the download

Open Downloads, select the three dots beside the file, then choose Keep → Show more → Keep anyway.

02Windows protected your PC

After verifying the file came from the official WWRecorder release, choose More info and then Run anyway if Windows offers it.

03Smart App Control blocks it

There is no one-file bypass. Use Microsoft Store where possible before considering a device-wide security change.
