Blocked by Windows / Browser?

Because this application is new and self-published, Microsoft Edge and Windows Defender SmartScreen might temporarily flag it as "isn't commonly downloaded." This is a standard automatic check for new indie software. (I've already submitted a request to Microsoft to whitelist it, but until it's processed, you can safely bypass it).

Here is how you can easily keep the file:

1

Edge Browser "Commonly Downloaded" Warning

If Edge blocks the download in the top-right downloads flyout, hover over the blocked file, click the three dots ..., and select Keep from the menu.

2

Confirm Trust

A secondary warning popup will appear saying "Make sure you trust the file". Click on the Show more ⌄ or More Info button, then select Keep anyway.

3

Windows Protected Your PC (SmartScreen)

When you run the .exe installer for the first time, Windows might show a blue SmartScreen warning. Simply click More info on the left, and then click the new Run anyway button that appears at the bottom.
