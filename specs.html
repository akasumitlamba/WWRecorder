01 / Capture topology

The actual frame path.

The engine builds the selected region from physical-pixel monitor segments, composites one contiguous BGRA frame, and streams it to FFmpeg.

01INPUTMSS monitor grabs

Each intersecting display is sampled in native desktop pixels, including displays at negative virtual coordinates.

→
02COMPOSENumPy BGRA canvas

Segments are mapped into image-local coordinates and resized only when logical-to-physical geometry requires it.

→
03CURSORWin32 top-down DIB

DrawIconEx applies Windows alpha/AND/XOR rules in a reusable 512 px cursor surface.

→
04PIPEFFmpeg rawvideo stdin

Contiguous BGRA bytes enter x264 as rawvideo; the temporary stream uses ultrafast, zerolatency and CRF 23.

→
05FINALCFR Matroska

Timing is rebuilt, audio is muxed, and the final pass uses veryfast, CRF 28, yuv420p and Opus.

02 / Timing laboratory

Wall time is authoritative.

A rawvideo pipe has no per-frame timestamps. WWRecorder measures active recording time independently so temporary CPU pressure cannot make motion run ahead of audio.

capture_clock.py
deadline += 1 / 30
if now > deadline:
    count_missed_slots()
    deadline = now

# never inject a stale catch-up frame

The next loop captures the newest screen state instead of filling a backlog with duplicate pixels.

final_timeline.ffmpeg
select = remove_pause_ranges
setpts = fit_survivors_to_wall_time
fps    = 30
tpad   = clone_final_frame_to_duration

The final result is stable CFR 30 while later pause ranges are compressed out exactly once.

03 / Audio graph

Short reads, resilient endpoints, voice-first mix.

System playback and microphone capture run independently. Both follow the current Windows default endpoint and preserve the measured unavailable interval if a device changes mid-session.

MMCSS

Priority where it matters

Each Windows audio capture worker requests the Audio Multimedia Class Scheduler profile; the whole process is not promoted globally.

DISCONTINUITY

No synthetic jitter gaps

Ordinary callback lateness is not treated as missing sound. Silence is inserted only for measured endpoint-unavailable time; WASAPI discontinuities remain diagnostics.

LIVE TOGGLES

Timeline stays continuous

Turning a source off writes zeros for that source instead of tearing down its stream, so re-enable is immediate and track duration remains aligned.

05 / State contract

Recording is a state machine.

idle→selecting→ready→preparing→recording↔paused→stopping→saving→idle

Start, stop and discard are idempotent at the coordinator boundary. A completed capture is never silently deleted, and user-visible failures say whether recovery media is safe.
