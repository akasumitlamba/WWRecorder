Standalone installer help

Find the message you see.
Follow only those steps.

Windows uses several different protections for downloads and applications. The illustrations below show where the relevant controls normally appear. Exact wording can vary with your Edge and Windows version.

Microsoft Store avoids most standalone-installer warnings.

Use the Store version first if it is available on your device. Windows handles acquisition and updates through the Store.

GET IT FROMMicrosoft
01 / MICROSOFT EDGE

“Isn’t commonly downloaded”

This message concerns download reputation. A new file or publisher may not yet have enough download history for Edge to recognise it.

  1. Open Edge Downloads.
  2. Select More actions (…) beside the WWRecorder file.
  3. Choose Keep.
  4. Choose Show more, then Keep anyway.

Only continue after confirming the address begins with github.com/akasumitlamba/WWRecorder/releases/.

View Microsoft’s screenshots and guidance →
02 / WINDOWS SMARTSCREEN

“Windows protected your PC”

This blue prompt appears when you run an application that Windows does not recognise. It is different from the Edge download warning.

  1. Verify that you downloaded the official WWRecorder setup.
  2. Select More info.
  3. Check that the app name is the expected WWRecorder installer.
  4. If Windows offers it and the source is correct, select Run anyway.

Stop if the warning reports known malware, the filename is unexpected, or you did not initiate the download.

Learn how Microsoft Defender SmartScreen works →
03 / SMART APP CONTROL

No “Run anyway” option

Smart App Control is stricter. Microsoft says there is currently no bypass for one specific application. It may block an unsigned application when its cloud service cannot make a confident safety prediction.

Recommended: install WWRecorder from Microsoft Store instead of changing a device-wide security setting.

If you intentionally decide to change it, open Windows Security → App & browser control → Smart App Control settings. Read the Windows warning before switching it off. Recent Windows updates may allow it to be enabled again, but availability and policy differ across devices.

Turning Smart App Control off changes protection for other applications too. Company or school devices may prevent the change; contact the administrator rather than working around policy.
Read Microsoft’s current Smart App Control FAQ →

Concerned about security?

Check the installer’s SHA-256 fingerprint.

A matching fingerprint confirms that the downloaded file is byte-for-byte identical to an installer fingerprint published on this site. It does not replace Windows security checks.

  1. Open PowerShell in Windows.
  2. Run this command in PowerShell:
    Get-FileHash -Algorithm SHA256 "C:\path\to\WWRecorder_Setup.exe"
    Replace "C:\path\to\WWRecorder_Setup.exe" with your downloaded installer path (or drag and drop the EXE into PowerShell).
  3. Copy the 64-character value shown under Hash, then paste or type it below.

No file is uploaded. The comparison happens in this page.

“Virus detected”

Open Windows Security → Virus & threat protection → Protection history. Do not restore a file identified as known malware. Download again from the official stable release and report the detection if it continues.

Work or school computer

Managed policy can remove Keep or Run anyway. Ask your administrator to approve the Store listing or installer. Do not bypass organisational security.

Windows in S mode

S mode limits installation to Microsoft Store. Use the Store listing, or review Microsoft’s S mode guidance before changing Windows mode.

Incomplete or damaged file

Delete the partial download, remove it from the browser’s Downloads list, confirm free disk space, and download it again over a stable connection.

Still blocked?

Include the exact warning text, Windows version, download route and installer filename in a support issue. Do not post private recordings or unreviewed logs.
