Security advisory: CVE-2026-8461

Update older WWRecorder installations to 1.7.1 before opening untrusted videos. Versions before 1.7.1 do not include this security update.

A flaw in FFmpeg’s MagicYUV decoder can let a specially crafted video crash an application or, in some circumstances, run malicious code. Exposure depends on whether vulnerable media libraries decode the file.

WWRecorder 1.7.1 updates both the recording/export encoder (FFmpeg 9.0.2) and playback libraries (FFmpeg 9.0.1 through Qt 6.12.0). For older installations, avoid opening media from untrusted sources until updated.

Download WWRecorder_Setup_1.7.1.4.exe from the latest GitHub release (tag v1.7). That release is a normal release, not a prerelease. There is no separate v1.7.1 GitHub Release. Check SHA-256 d0c7cf976cd9656c60b9e938e9abc11f72990afd610495b28f845643bea3fdf0, or compare it on this site. The EXE is unsigned.

The standalone EXE checks GitHub’s latest non-prerelease release, which is tag v1.7, and the Setup file on that release is WWRecorder_Setup_1.7.1.4.exe. An installation that already shows 1.7.1 will not treat that tag as a newer update. Microsoft Store installs update through the Store. This site cannot confirm the Store package version [PLACEHOLDER: Microsoft Store package version that includes CVE-2026-8461].

References: FFmpeg security advisories and Ubuntu’s CVE description.

Version 1.7.1 — 29 October 2026

Application 1.7.1 is on the latest GitHub release, tag v1.7, published 29 October 2026. The Setup file is WWRecorder_Setup_1.7.1.4.exe. There is no separate v1.7.1 GitHub Release.

Added

  • Choose a microphone or the Windows default. The list refreshes while it is open, including wireless devices. If that microphone disconnects, the current recording keeps that input and the next recording uses the Windows default.
  • Keycast shows keys, shortcuts, clicks and scrolling in the recording. Before you turn it on, a warning explains that passwords and typing outside the selected area can appear in the video. Keycast does not mask passwords.
  • Administrators can turn off Keycast or automatic clipboard copying with DisableKeycast and DisableAutomaticClipboard. See deployment instructions.
  • Place the dock on any screen edge.
  • Mute several sections of a video, along with trim, cuts and timed captions.
  • The Windows EXE and Microsoft Store editions provide the same recording and editing features.

Improvements

  • Recording, playback, editing and annotation controls are refreshed, and annotation controls fit more screen sizes.
  • Recent Files cards are more compact, file actions are clearer, and Settings is reorganized.
  • Processing and saved notifications are smaller, with thumbnails and useful actions.
  • The Keycast privacy warning is clearer and uses a compact illustration.
  • The Windows installer artwork and icons are updated.

Fixed

  • Confirmations, menus and tooltips, including Delete File and Discard Recording, no longer sit behind the floating controls.
  • When capture slows, the previous screen image is held so the picture stays aligned with the sound.
  • Some USB and Bluetooth microphone recordings that failed now record, and an unavailable device is reported.
  • The recording area, its outline and click-through controls stay where you put them.
  • The dock stays in place after a settings change or an interrupted drag.
  • Annotation text lands where you place it, erasing works while zoomed, drawings do not linger, and the laser pointer renders correctly.
  • Trim and cut ranges, including their summaries, stay where you set them. Caption positions on the timeline stay with them.
  • Timeline previews are less slow, and the last playback frame is present.
  • Deleted captions disappear. Caption edits made while playback is paused are kept.
  • A failed save keeps the recovery files. An action on one recording does not change another.
  • WWRecorder starts on Windows installations where it previously failed to open.
  • A failed rename no longer drops unsaved edits. Export works when the video width or height is an odd number of pixels.
  • The installer handles a running copy during setup. If Windows asks, quit the older copy once and run the installer again.

Version 1.6 — 8 September 2026

This version predates the CVE-2026-8461 security update. Its installer is WWRecorder_Setup_1.6.3.exe, published 8 September 2026. It updates earlier 1.6 installations and keeps the same application identity and settings. The EXE is unsigned.

Capture and recording

  • Recordings and screenshots stay aligned on monitors that use different Windows scaling, including screens to the left of or above the main display. Mixed scaling uses each monitor’s own pixel map.
  • A paused section is removed once, and the audio stays aligned with the video.
  • If the microphone or system-sound device disconnects during a recording, WWRecorder shows a warning.
  • A recording does not look ready when it has already failed to start.
  • Very large Windows accessibility cursors are not clipped, and temporary cursor resources are released.
  • Only one copy of WWRecorder runs, and it does not ask for administrator permission to do that.
  • The dock Record button works while a sidebar is open. The dock does not jump when the resolution, monitor or taskbar changes during an animation.
  • WWRecorder starts on other PCs where startup had failed.
  • Shortcut modifier keys are cleared after you return from a Windows security or UAC prompt.

Annotation, screenshots and editing

  • Clear All puts drawings back in their original order when you undo.
  • The line-thickness menu stays on the screen.
  • Save and Save As finish writing the new image before replacing the original, so a failed write keeps the original and does not save twice to the same path.
  • Reset to Defaults also restores the default text size.
  • The laser pointer stays on screen while you draw. After the last stroke it waits three seconds, then the group fades out together over one second. The photo editor is unchanged.
  • Cuts that touch or overlap are merged before export, so playback does not stutter or drift.
  • Exported captions follow the editor preview more closely in size and in bold or italic style on HD, 1440p and 4K video.
  • Caption temporary files are removed after an export succeeds, fails or is cancelled.
  • Closing the editor during a failed export no longer leaves it frozen.
  • When a damaged video cannot be decoded, its timeline is turned off.
  • Fullscreen playback controls stay visible above a taskbar that hides automatically.
  • Unsaved captions and cuts are kept whether a rename fails or succeeds.
  • A file delete that fails is no longer silent.

Files and messages

  • Photos offer Open & Edit, Copy, Rename and Delete. Videos offer Play, Edit, Copy, Rename and Delete.
  • Recent Files builds previews as those files reach the visible list. Tips describe photos, videos, search and preview loading, and each tip uses one line.
  • Processing and Saved notices appear on the monitor where the capture was made.
  • Unknown scripts and programs cannot be opened from Recent Files or from a save notification.
  • Common errors are explained in plain language, and Tab moves through the controls.
  • A failure to reach the update server is reported separately from already being on the latest version.
  • The developer-mode note in Settings wraps inside the sidebar.

Older releases

Earlier installers remain in the GitHub release history. Versions before 1.7.1 do not include the CVE-2026-8461 update. Use WWRecorder_Setup_1.7.1.4.exe on the latest release.
