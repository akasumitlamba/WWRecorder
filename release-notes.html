Security advisory: CVE-2026-8461

Update older WWRecorder installations to 1.7.1 before opening untrusted videos. Versions before 1.7.1 do not include this security update.

A flaw in FFmpeg’s MagicYUV decoder can let a specially crafted video crash an application or, in some circumstances, run malicious code. Exposure depends on whether vulnerable media libraries decode the file.

WWRecorder 1.7.1 updates both the recording/export encoder (FFmpeg 9.0.2) and playback libraries (FFmpeg 9.0.1 through Qt 6.12.0). For older installations, avoid opening media from untrusted sources until updated.

Review the 1.7.1 preview release and installer and verify its SHA-256. The EXE is unsigned. Store users should check Microsoft Store for updates and review the installed version. The website cannot check your installed app or confirm a Store rollout.

References: FFmpeg security advisories and Ubuntu’s CVE description.

Version 1.7.1 — 29 October 2026

Changes since the v1.6 release, including Windows installer revision 1.7.1.1.

Added

  • Choose a microphone, or follow the Windows default.
  • Keycast shows keys, shortcuts, clicks and scrolling in recordings. Before enabling it, a warning explains that passwords and typing outside the selected area can appear in the video.
  • Administrator policies DisableKeycast and DisableAutomaticClipboard, added in 1.7.1. See deployment instructions.
  • Dock placement on any screen edge and multiple audio-mute sections in the editor.

Fixed

  • Fixed: audio/video timing during uneven capture load by holding the previous screen image during missed frame slots.
  • Fixed: microphone selection changing unexpectedly and some USB/Bluetooth microphone recording problems.
  • Fixed: dock position moving after settings changes or interrupted drags.
  • Fixed: incorrect annotation text placement, erasing at zoom and lingering drawings.
  • Fixed: slow timeline previews, missing final playback frames and captions remaining after deletion.
  • Fixed: trim and cut ranges changing unexpectedly during editing.
  • Fixed: exports failing for videos with odd pixel dimensions.
  • Fixed: saving failures losing access to recovery media and overlapping recording actions affecting another take.
  • Fixed: startup failures on some Windows installations and incorrect installer icons.

Installer and checksums.

Version 1.6 — 8 September 2026

The v1.6 release includes installer version 1.6.3. It predates the security update above.

  • Fixed: edited screenshots being left partially saved after a write failure.
  • Fixed: overlapping cuts causing brief playback stutters or audio drift.
  • Fixed: captions exporting with different sizing or formatting from the preview.
  • Fixed: export errors leaving caption temporary files behind.
  • Fixed: more than one copy of WWRecorder running at a time.
  • Fixed: recordings overwriting captures with the same timestamp.
  • Fixed: audio gaps caused by ordinary scheduling delays.

Older releases

Historical installers are retained in GitHub release history. Use 1.7.1 for the security update described above.
