# Automated actions

- Capture: select/resize/move, start/pause/stop/discard and recovery guards.
- Annotation: tool switches, history, captions, erasing and cursor alignment.
- Player/editor: playback, speed, frame capture, trim/delete/text/mute and save.
- Dock/settings: edges, layouts, drag/focus behavior and save/cancel/reset.
- Distribution: edition guards, Qt payload, startup and updater origin checks.

Every automated test supplies expected dialog responses; unexpected dialogs fail.
No human action is required while the runner executes. Reports list skipped
platform/hardware checks explicitly.
