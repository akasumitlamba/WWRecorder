Why WWRecorder?

Built with efficiency at its core using FFmpeg and Python.

Low CPU Usage

Optimized for older hardware using the x264 ultrafast preset and CRF encoding.

Crash Resilient

Recorded in .mkv format. If your PC loses power, your video is still saved.

Invisible UI

The control pill uses Windows Affinity API to hide itself from your recordings.

Dual Audio

Capture system loopback and microphone simultaneously with zero latency.

Technical Requirements

  • OS: Windows 10 (2004+) or Windows 11
  • Processor: Intel Core i3 (2nd Gen+) or equivalent
  • Graphics: Any integrated or dedicated GPU
  • Dependencies: FFmpeg (bundled)
