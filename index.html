Capabilities

Built for the real world.

Every feature engineered for reliability on hardware that can't afford to choke.

Crash-Resilient .MKV

MKV's self-healing index means your recording survives unexpected shutdowns, BSOD, or power loss. No more corrupted files from incomplete writes.

.mkv recoverable

Zero-Latency Audio Toggle

Mute system audio or mic mid-recording. No restart needed. Silence is written as zero frames - timeline never breaks.

WASAPI mic boost ×2.5

Flawless Screen Recording

Press Shift+Backspace to record instantly. Pause seamlessly—our engine ensures perfect A/V sync and stable 30 FPS without dropping frames.

stable 30 FPS clipboard-ready A/V sync

Instant Screenshot Capture

Press Shift+Home to open the region selector in screenshot mode. The captured PNG is saved and auto-copied to clipboard - image and file path ready to paste immediately.

PNG clipboard-ready configurable hotkey

Auto-Copy to Clipboard

Recordings and screenshots are automatically copied to your clipboard the moment they save. Paste directly into Discord, Slack, or your file manager - zero extra steps.

recordings screenshots configurable

Edge Dock & Recent Files

A compact grabber snaps to either screen edge. Hover to expand action buttons, or open the side panel to view recordings, screenshots & edit them. drag and drop the files anywhere in the system.

Settings sidebar - output, hotkeys, toggles, appearance.

01

Hover the Edge Dock

An edge-snapping dock sits at the side of your screen. Hover to reveal four buttons - Screenshot, Record, Recent Files, and Settings. Drag it anywhere along the edge.

02

Select a Region

Click Record (or press Shift+Backspace), or click Screenshot (or press Shift+Home). A dark overlay appears - drag to select the area you want to capture.

03

The Pill Appears (Recording)

A minimal borderless Pill control bar anchors to your screen. It's always-on-top and invisible to your recording.

04

Browse Recent Files

Open the sidebar to see all recordings and screenshots with thumbnails. Hover videos for a preview. Rename, delete, copy to clipboard, or drag and drop anywhere.

05

Configure Everything

Open Settings to customise output folder, hotkeys, audio defaults, clipboard behaviour, and UI font size - all from a slide-in sidebar.

Technical Specs

Under the hood.

Parameter Value Notes
Video Codec libx264 H.264, yuv420p pixel format
Preset veryfast Better compression without lagging the capture engine
CRF Quality 30 Higher = smaller file. 30 achieves massive size reduction.
Frame Rate 30 FPS Hard-coded for stability on older CPUs
Container .mkv Recoverable if app/system crashes mid-recording
System Audio WASAPI loopback via soundcard 0.4+, Native/48kHz stereo, real-time sync
Microphone Default mic Boosted ×2.5, clipped to [−1, 1]
Audio Output AAC 96k amix for dual streams, direct copy for single
Screen Capture mss BGRA → BGR24; hardware cursor composited via pywin32
Config %APPDATA%\WWRecorder config.json - hotkey, output folder, defaults
Pill Visibility WDA_EXCLUDEFROMCAPTURE Windows 10 build 19041+. Silently ignored older.
Hotkey (Record) Shift+Backspace Configurable. Works when minimised.
Hotkey (Screenshot) Shift+Home Configurable. Opens region picker in screenshot mode.
Screenshot Format .png Saved to output folder. Auto-copied to clipboard if enabled.
Clipboard Integration QMimeData Both file URL and image data on screenshot; file URL on recording.

PRIVACY POLICY

No Data Collection

WWRecorder does not collect, transmit, store, or share any personal data, usage analytics, crash reports, or telemetry of any kind. The application runs entirely on your local machine.

Local Storage Only

All configuration is stored locally in %APPDATA%\WWRecorder\config.json. Recordings are saved to the output folder you configure. No files are uploaded anywhere.

Registry

If you enable auto-start, a single entry is written to HKCU\Software\Microsoft\Windows\CurrentVersion\Run. This is a standard Windows mechanism and can be removed via Settings.

No Network Access

WWRecorder makes no network requests at any time. There are no update checks, licence servers, or remote APIs involved in its operation.

Third-Party Libraries

WWRecorder bundles FFmpeg (LGPL/GPL depending on build), mss, soundcard, PyQt6, pynput, numpy, and pywin32. These operate entirely locally. No third-party service receives data.
