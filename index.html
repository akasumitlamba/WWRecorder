Built for the real world.

Stable 30 FPS on Low-End CPUs

H.264 with the superfast preset keeps encoding off the critical path. Intel i3 with integrated graphics delivers smooth, tear-free recordings without dropped frames.

Crash-Resilient .MKV

MKV's self-healing index means your recording survives unexpected shutdowns, BSOD, or power loss. No more corrupted files from incomplete writes.

.mkv recoverable

Select a Region

Launch from the system tray or press Shift+Backspace. A dark overlay appears - drag to select the area you want to capture.

The Pill Appears

A minimal borderless Pill control bar anchors to your screen. It's always-on-top and invisible to your recording.

Toggle Audio On-the-Fly

Hit the speaker or mic icon to mute/unmute instantly. No restart. Silence is written as zero frames - the timeline never breaks.

Pause & Resume

Pause re-sends the last frame at 30 FPS to keep FFmpeg's clock alive. A/V stays perfectly synced across the single continuous .mkv.

Stop & Save

Click the red stop button. Video + audio mux in ~1–3 seconds. File lands in Videos\WWRecorder - or wherever you configured.

Technical Specs

Under the hood.

Parameter Value Notes
Video Codec libx264 H.264, yuv420p pixel format
Preset superfast Lower CPU than ultrafast, much better compression
CRF Quality 28 Higher = smaller file. 28 is excellent for screencasts.
Frame Rate 30 FPS Hard-coded for stability on older CPUs
Container .mkv Recoverable if app/system crashes mid-recording
System Audio WASAPI loopback via soundcard 0.4+, 48 kHz stereo
Microphone Default mic Boosted ×2.5, clipped to [−1, 1]
Audio Output AAC 192k amix for dual streams, direct copy for single
Screen Capture mss BGRA → BGR24; hardware cursor composited via pywin32
Config %APPDATA%\WWRecorder config.json - hotkey, output folder, defaults
Pill Visibility WDA_EXCLUDEFROMCAPTURE Windows 10 build 19041+. Silently ignored older.

PRIVACY POLICY

No Data Collection

WWRecorder does not collect, transmit, store, or share any personal data, usage analytics, crash reports, or telemetry of any kind. The application runs entirely on your local machine.

Local Storage Only

All configuration is stored locally in %APPDATA%\WWRecorder\config.json. Recordings are saved to the output folder you configure. No files are uploaded anywhere.

Registry

If you enable auto-start, a single entry is written to HKCU\Software\Microsoft\Windows\CurrentVersion\Run. This is a standard Windows mechanism and can be removed via Settings.

No Network Access

WWRecorder makes no network requests at any time. There are no update checks, licence servers, or remote APIs involved in its operation.

Third-Party Libraries

WWRecorder bundles FFmpeg (LGPL/GPL depending on build), mss, soundcard, PyQt6, pynput, numpy, and pywin32. These operate entirely locally. No third-party service receives data.
