1. Summary

WWRecorder records the screen area, system sound and microphone sources you explicitly choose. Capture, editing and export processing happens on your Windows device. The application does not require an account and does not include an advertising profile, usage analytics SDK, telemetry service or a service that uploads your captures to the developer.

2. Data the application handles

Capture content

Depending on the controls you enable, WWRecorder handles screen pixels, mouse pointer imagery, system playback audio and microphone audio. Screenshot and annotation tools handle the images, text and drawings you create. The video player/editor handles media files you open and the edits you request.

Preferences and shortcuts

The app stores settings such as output folder, audio defaults, shortcut combinations, sidebar size, dock position and startup preference. Global shortcut listening reacts to configured key combinations; WWRecorder does not intentionally create a history of general typing.

Clipboard and drag-and-drop

If auto-copy is enabled or you choose Copy, the app places captured media or a file reference on the Windows clipboard. Dragging a file lets the target application receive it. The receiving application’s privacy practices then apply.

Diagnostics

Local application logs and crash information may include timestamps, component names, error details and local file paths needed to diagnose failures. Do not share logs publicly without reviewing them for personal paths or filenames.

3. Where data is stored

  • Recordings, screenshots, edited copies and extracted frames are stored in the output folder you select.
  • Preferences are stored in %APPDATA%\WWRecorder\config.json.
  • Application and crash logs are stored under %APPDATA%\WWRecorder.
  • Recording work/recovery media is kept in a hidden .wwr_temp folder under the selected output folder. Recent recoverable media may be retained after a failed finalization; stale orphan media is eligible for cleanup after seven days.
  • If Start with Windows is enabled, WWRecorder adds a per-user startup entry in Windows.

The developer does not operate a WWRecorder cloud-storage account for this data.

4. Application network activity

WWRecorder can contact the GitHub Releases API over HTTPS to check the newest public stable release version. Available updates direct users to the Microsoft Store. Developer mode can open the public GitHub Releases page when you choose that action. The app does not silently publish or upload your captures.

GitHub and Microsoft may receive ordinary connection data such as IP address, request time, browser/app user agent and requested URL under their own policies. Links you open in a browser are governed by the destination’s terms and privacy practices.

5. This website

This is a static GitHub Pages site. It has no WWRecorder account system, advertising pixel or product-analytics script. To show the current stable standalone installer, the download page requests GitHub’s public /releases/latest API endpoint in your browser. Clicking Store, GitHub, Microsoft documentation or support links sends you to those third-party services.

GitHub Pages and your network provider may process technical request logs required to serve the site. See GitHub’s Privacy Statement.

6. Your controls

  • Choose the output folder and which audio sources are enabled.
  • Turn automatic clipboard copying or Start with Windows on or off in Settings.
  • Delete recordings, screenshots and edited files through the app or File Explorer.
  • Close WWRecorder before deleting local configuration or diagnostic files under %APPDATA%\WWRecorder.
  • Remove recovery media only after confirming your completed recording is safe.

Because the app has no developer-operated user account or capture cloud, there is no remote capture library for the developer to retrieve or delete.

7. Security and retention

WWRecorder minimizes remote handling by processing media locally and using HTTPS for release checks and external links. No storage or transmission method is completely risk-free. Protect the Windows account and output folders you use, review content before sharing it, and keep Windows security protections enabled.

Local media remains until you delete it. Settings and logs remain until reset, uninstall cleanup or manual deletion. Stale recording work files are eligible for cleanup after the recovery-retention period.

8. Children’s privacy and policy updates

WWRecorder is a general-purpose capture utility and is not directed specifically to children. The app does not knowingly collect personal information from children through a developer-operated account or telemetry service.

This policy may change when app behavior, distribution or legal obligations change. The effective date at the top will be updated, and material changes will be reflected on this page.

9. Contact

For privacy questions or if the app appears to behave differently from this policy, open a support issue. Do not attach private captures, audio, access tokens or unreviewed diagnostic logs.
