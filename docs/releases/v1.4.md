# WWRecorder 1.4.0

## Added

- Video player and editor with a timeline, trim, cuts, timed text and audio controls.
- Background export with progress feedback.
- Settings grouped into capture, audio, shortcuts and advanced options.
- Resizable annotation text and multiline input with Shift+Enter.
- Background update checks and installer downloads.

## Fixed

- Reduced startup delays and preview memory use.
- Improved audio/video quality and global shortcut handling.
- Improved annotation window visibility.
- Added progress feedback while recordings are saved and compressed.
