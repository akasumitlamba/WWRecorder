# WWRecorder 1.2.0

## Improvements

- Improved audio/video synchronization and handling of native audio sample rates.
- Smaller H.264 recordings with background compression.
- Saving continues after recording controls close.
- Open a saved recording from its notification.
- System sound recording is off by default.

## Fixes

- Added Discard to the recording controls.
- Fixed capture borders and region sizing on scaled displays.
- Improved audio clarity, tooltip visibility and dock/sidebar interactions.
- Fixed temporary files appearing while recording.

## Installation

Download the Windows installer attached to this release. Review any Windows warning and verify the download came from the official repository before continuing.
