> Historical release: this version predates the CVE-2026-8461 security update. Use [WWRecorder 1.7.1](https://github.com/akasumitlamba/WWRecorder/releases/tag/v1.7.1) before opening untrusted videos.

### Real-Time Screen Annotation

* Draw directly on the screen during recording.
* Annotations appear in the recorded video if they fall inside the recording region.

### Global Live Annotator

* Draw over the desktop.
* Open annotations independently of recording.
* Can be activated even when recording is not running.

### Floating Annotation Toolbar

* Dedicated **Annotation Pill** that appears at the bottom center of the screen.
* Can be manually closed by the user.
* Remains visible during recording if placed inside the capture area.

### Annotation Tools

* Pencil drawing tool
* Highlighter tool
* Text writing tool
* Shape tools:

  * Circle
  * Rectangle
  * Arrow

### Color & Thickness Controls

* Multiple color options for annotations.
* Adjustable stroke thickness for drawing tools.

### Screenshot Annotation Editor (WWRecorder : Annotate)

* Screenshots open in a built-in editor for annotation.
* Users can edit screenshots with the same annotation tools.

### Screenshot Editing Tools

* Draw annotations on screenshots.
* Add text.
* Highlight content.
* Draw shapes.
* Crop screenshots.

### Screenshot Export Options

* Save edited screenshot.
* Save As to a different file.
* Copy annotated screenshot directly to clipboard.

### Annotation Dock Shortcut

* New **Annotate button** added to the dock sidebar.
* Allows launching the live annotator without starting a recording.

### Multi-Window Screenshot Editing

* Multiple screenshots can be opened and edited simultaneously.

### Text Editing Controls

* Adjustable text size.
* Text formatting options:

  * Bold
  * Italic
  * Underline
* Multi-line text support.

### Zoom & Navigation in Screenshot Editor

* Zoom in/out of screenshots.
* Pan around the image when zoomed.

### Straight-Line Drawing Mode

* Hold **Ctrl while drawing** to create straight lines with drawing tools.
