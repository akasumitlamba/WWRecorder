# WWRecorder 1.5.0

## Added

- Floating saved-capture notifications with previews, filenames and file actions.
- Rename recordings and screenshots directly from their saved notification.
- Sound feedback when captures are saved.

## Fixed

- Fixed crashes when renaming recordings and screenshots.
- Fixed edge-dock hover animations becoming slow over time.
- Fixed tooltips remaining visible in captures.
- Reduced delays when opening recording, screenshot and annotation tools after startup.
- Improved visibility of saved-capture notifications.
