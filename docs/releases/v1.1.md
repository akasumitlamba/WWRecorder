# WWRecorder 1.1.0

## Added

- Region screenshots with Shift+Home.
- Floating edge dock for quick access to capture tools.
- Recent Files sidebar with previews, renaming and copying.
- Settings sidebar with separate recording and screenshot shortcuts.
- Optional automatic clipboard copying after saving.

## Fixed

- Audio choices now persist between recording sessions.

## Settings

Use the Settings sidebar to change shortcuts, dock placement, interface size and automatic copying. Manual configuration-file editing is not required.
