# WWRecorder 1.0.0

Initial Windows release.

- Select an area and record H.264 video in an MKV file.
- Capture system sound and microphone audio.
- Pause and resume in one recording.
- Change audio controls while recording.
- Use floating recording controls, a tray icon and a configurable recording shortcut (Shift+Backspace by default).
- Optionally start with Windows.
- Install for the current Windows user.
